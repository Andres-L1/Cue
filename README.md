# Chedex Launcher

**Un solo lugar con las herramientas de Chedex para creadores de contenido.**

Ábrelo, elige una herramienta en la lista de la izquierda, mira de qué va y pulsa **Iniciar**. Sin ajustes complicados.

---

## Herramientas

### Teleprompter
Lee tu guion mirando a cámara. Se abre en una ventana que se queda **encima de todo** mientras grabas.

- Pega tu guion, pulsa **Preparar guion** y te avisamos cuando esté listo.
- El texto sube solo, y una línea naranja marca por dónde vas.
- Elige la velocidad y el tamaño de letra que te vengan bien.
- Pausa y sigue con la **barra espaciadora**, o con **Ctrl + Mayús + T** aunque estés en otra aplicación.
- Cambia la velocidad con las flechas **↑** y **↓**.

*Más herramientas, muy pronto.*

Ábrelo y sigue los pasos. ¿No sabes qué Mac tienes? Menú  > *Acerca de este Mac*.

La primera vez, Windows o Mac pueden mostrar un aviso de seguridad porque la aplicación aún es nueva. Puedes continuar: es normal.

## Siempre al día

No tienes que volver a descargar nada. Cuando hay una versión nueva, el launcher la descarga solo y te avisa con un botón **Reiniciar y actualizar**.
